# 🔢 Magic Figures

### Think. Arrange. Solve!

**Magic Figures** is an interactive mathematical puzzle game designed to make number puzzles fun, engaging, and challenging. Arrange numbers in different geometric figures and solve puzzles by satisfying the mathematical conditions of each shape.

Explore **51 puzzles across 10 difficulty levels**, from beginner-friendly magic crosses to challenging number arrangements.

---

## ✨ Features

- 🧩 **51 unique puzzles**
- 📈 **10 difficulty levels**
- 🔢 Number-placement challenges involving triangles, squares, circles, stars, rings, and other figures
- 🖱️ Interactive drag-and-drop gameplay
- ⭐ Star-based puzzle completion
- 🏆 Achievements and badges
- 📊 Progress tracking and statistics
- 🔥 Daily challenges and streak tracking
- 👤 Player profiles
- 🎨 Multiple themes, including light and dark mode
- ⚙️ Customizable settings
- 🔊 Sound effects and vibration feedback
- 📱 Responsive design for mobile and desktop
- 💾 Progress saved locally in the browser

---

## 🎮 How to Play

1. Choose a difficulty level.
2. Select a mathematical puzzle.
3. Drag the available numbers into the empty positions.
4. Make sure the numbers satisfy all the conditions shown in the puzzle.
5. Check your answer.
6. Complete puzzles to earn stars and progress through the game.

Each puzzle has its own mathematical rules, so think carefully about how the numbers work together!

## 💾 Data & Privacy

Game progress, settings, and player data are stored locally in the browser using Local Storage.

This means the data is associated with the browser and device being used. Clearing browser storage may erase saved game progress.

This project does not currently use a cloud database or online account synchronization.
