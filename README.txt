MAGIC FIGURES - website / installable app

1. Upload this whole folder to a free host (Netlify Drop, Cloudflare Pages, GitHub Pages, Vercel).
   Keep the file names exactly as they are. index.html is the game.
2. Open the https link on a phone. Chrome/Android: menu > Install app.
   iPhone Safari: Share > Add to Home Screen.
3. It then opens full screen with its own icon and works offline.

Notes: accounts and progress are stored in each person's own browser (no server).
A worldwide leaderboard or cross-device login needs an online backend such as Supabase or Firebase.
